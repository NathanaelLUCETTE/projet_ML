Pokémon Clustering Project
This project applies unsupervised learning techniques to analyze Pokémon characteristics and uncover meaningful groups based on two feature families: Stats and Power/Rarity.
The workflow includes preprocessing, scaling, clustering (K‑Means, DBSCAN, Agglomerative), PCA visualization, and generalization tests on fan‑made and Generation 9 Pokémon.

Contents:

/ – Python script implementing the full analysis + Final report (PDF + Word)
/data/ – Raw, cleaned, and scaled datasets

PCA plots and clustering results included in the report

Goal:  
Identify robust Pokémon archetypes and evaluate the stability and generalizability of clustering methods across datasets.
